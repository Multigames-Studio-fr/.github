
# Multigames Studio (organisation)

Bienvenue sur le dépôt `.github` de l'organisation Multigames-Studio-fr.

Ce dépôt contient des ressources partagées pour l'organisation : modèles de issues et PR, guides, templates et informations générales.

## Mission

Multigames Studio conçoit et publie des jeux et outils ludiques en mettant l'accent sur la créativité, la qualité et l'expérience joueur. Nous collaborons en open source quand cela apporte de la valeur à la communauté.

## Répertoires et contenus importants

- `.github/ISSUE_TEMPLATE/` : modèles d'issues (bug, feature, question).
- `.github/PULL_REQUEST_TEMPLATE.md` : modèle de Pull Request.
- `CODE_OF_CONDUCT.md` : code de conduite de l'organisation.
- `CONTRIBUTING.md` : guide de contribution commun.

(Si un fichier n'existe pas encore dans ce dépôt, vous pouvez proposer sa création via une Pull Request.)

## Comment contribuer

1. Trouvez un dépôt de l'organisation qui vous intéresse.
2. Lisez le `README` du projet et `CONTRIBUTING.md` s'il existe.
3. Ouvrez une issue pour discuter d'une grosse fonctionnalité ou d'un changement important.
4. Forkez le dépôt, créez une branche de travail claire (ex: `feat/nom-fonction` ou `fix/description`).
5. Faites des commits atomiques et bien décrits.
6. Ouvrez une Pull Request en expliquant le but et les impacts du changement.

Conseils :

- Respectez le style de code du projet (linters/configs).
- Ajoutez des tests pour les changements fonctionnels quand c'est pertinent.
- Conservez les messages de commit en français ou en anglais selon la langue principale du dépôt.

## Code de conduite

Merci de respecter les autres contributeurs. Si vous n'en avez pas encore, ajoutez un fichier `CODE_OF_CONDUCT.md` pour formaliser les règles de bonne conduite.

## Licence

Chaque dépôt doit indiquer sa licence. L'organisation n'impose pas une licence unique ici ; vérifiez le fichier `LICENSE` du projet concerné.

## Contacts

- Mainteneurs : voir la liste des responsables dans chaque dépôt.
- Pour des questions générales, ouvrez une issue dans le dépôt concerné ou contactez les mainteneurs listés.
