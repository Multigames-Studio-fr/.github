# Guide de contribution - MultiGames Studio

Merci de vouloir contribuer à MultiGames Studio ! Ce guide court explique comment démarrer et ce qu'on attend des contributions.

1. Trouver un projet
- Choisissez le dépôt correspondant à votre idée (plugin, site, outils, etc.).

2. Lisez la documentation
- Lisez le `README.md` du dépôt et, si présent, son `CONTRIBUTING.md` local.

3. Ouvrez une issue
- Pour une nouvelle fonctionnalité majeure ou un bug complexe, ouvrez d'abord une issue pour en discuter.

4. Workflow Git
- Forkez le dépôt et créez une branche nommée clairement : `feat/description`, `fix/description`, `docs/…`.
- Faites des commits atomiques et lisibles.
- Rebase ou merge régulièrement la branche principale si nécessaire.

5. Tests & Qualité
- Respectez le style de code du projet (linters et formatters).
- Ajoutez des tests automatisés pour les changements fonctionnels quand possible.

6. Pull Request
- Ouvrez une PR décrivant le but, les changements et les éventuels impacts.
- Liez l'issue associée si applicable.
- Mentionnez les mainteneurs si vous avez besoin d'une revue rapide.

7. Attente & Révisions
- Répondez aux commentaires de revue et mettez à jour la PR.

Remerciements
- Merci pour vos contributions ! Toutes les contributions (code, documentation, tests, idées) sont appréciées.
